# Pyramid Principle and SCQA

This reference summarizes two widely used communication frameworks. Apply them as tools, not rigid templates.

## Pyramid Principle

The core idea is to state the governing answer or recommendation first, then support it with a small number of logically grouped arguments. Evidence and detailed analysis sit below the claims they support.

A simple shape:

```text
Main answer / recommendation
├── Reason 1
│   └── Evidence or example
├── Reason 2
│   └── Evidence or example
└── Reason 3 (only if genuinely needed)
    └── Evidence or example
```

### When it helps

- Executive or stakeholder communication.
- Decision memos and recommendations.
- Complex explanations where readers need the conclusion before details.
- Research findings that need to be converted into a clear implication.

### How to apply it

1. Write the main answer as a complete statement, not a topic label.
2. Choose supporting reasons that actually support that answer.
3. Group reasons at the same logical level.
4. Place evidence beneath the claim it supports.
5. Check whether each point adds distinct value and whether a counterargument changes the conclusion.

Do not force exactly three reasons. Do not place a conclusion first when the user explicitly asks for open-ended exploration, a suspenseful narrative, or a step-by-step derivation.

## SCQA

SCQA stands for Situation, Complication, Question, Answer.

- **Situation:** establish the context the reader needs.
- **Complication:** identify the change, tension, or problem that makes the situation consequential.
- **Question:** make the decision or issue explicit, when it is not already obvious.
- **Answer:** give the proposed resolution.

Use SCQA to frame a complex problem or narrative, especially when readers need context before they understand why the answer matters. It is often unnecessary for direct chat responses because the question is already explicit.

## Example

**Overbuilt version:**

“Organizations operate in competitive markets. Technology changes quickly. Teams face constraints. The question is how they should proceed. There are many options...”

**Pyramid-style answer:**

“Run a two-week pilot before committing to a company-wide rollout. It tests adoption at low cost, exposes integration issues, and gives the team evidence before the migration becomes difficult to reverse.”

If an SCQA introduction is needed for a decision memo, the context and complication can precede that answer in a short opening. Do not prepend background to every answer merely to use the framework.

## Intellectual honesty

Frameworks organize arguments; they do not validate facts or prove causation. Confirm evidence independently, expose assumptions that matter, and preserve uncertainty. The name “Pyramid Principle” is associated with Barbara Minto's published work; this reference is an original practical summary, not a reproduction of a proprietary firm's internal materials.
